## 1. 分级门禁流程（先小后大，坏档位不浪费算力）

```
Stage A  契约层      1 题直连 + /props        ~1 min   → 任一 ❌ 立即终止本端口
   ↓ 全过
Stage B  质量快筛    12 题单调 + auto-eval   ~2–8 min → FAIL ≥3 即终止，不进 Stage C
   ↓ FAIL ≤2
Stage C  全量门禁    34 题 + auto-eval + attrib:regress:real
   ↓
Stage D  性能汇总    p50/p95、decode R、token 量、stop 率
   ↓
Stage E  生产适配    G1 真人认可率 / 人工盲评（离线不可判，单独标注）
```

**为什么分级**：IQ1_M 与 8085 都在第 1 题就暴露基础算术崩塌，跑 34 题只会得到一堆 FAIL 且白耗时间。门禁的价值是**尽早止损**。

## 2. Stage A · 契约层指标（1 题直连即可判）

| # | 指标 | 采集方式 | 合格线【设计值】 | 不合格 → 如何合格 |
|---|---|---|---|---|
| A1 | 服务可达 + 身份明确 | `GET /v1/models`、`/props` | HTTP 200；有 `id` / `ftype` / `n_ctx` / `temperature` | 启服务；核对 alias 与 GGUF 实际文件 |
| A2 | 非截断收敛 | 响应 `finish_reason` | **100% `stop`**；出现 `length` 该样本作废 | 请求层禁 `enable_thinking:true`；或提高 `max_tokens` + 换高精度档 |
| A3 | `content` 非空 + 思考分离正确 | `content` / `reasoning_content` | `content>0`；若开思考档须 `reasoning>0` 且 content 无 `<think>` | 检查 `reasoning_format`；当前各端口 `none` 已正确，勿动服务层 |
| A4 | 格式契约无污染 | 正则扫 `<...>` 占位符 / `</br>` / `<think>` 残留 / 自我纠缠词 | **0 污染** | 极低量化退化 → **换量化档**（采样参数救不回） |
| A5 | 五项字段齐全 | `prompt-ab` 的 `fields.hasCore` | **100%** | 换档；或 prompt 加显式格式约束 |
| A6 | 基础算术不崩 | 同题 `mx01` 驻点 / 极值配对 | 驻点 **±1**、增 `[-2,-1]∪[1,2]`、减 `[-1,1]`、`f(-1)=2 / f(1)=-2` | **只能换档**（bpw 信息损失不可逆，`temperature`/`top_p`/`seed` 无效） |
| A7 | 重复采样一致性 | 同题 ≥2 次（统计口径 ≥8 次） | 结论一致率 **≥90%** | `temperature` → 0.2、固定 `seed`、换高精度档 |

> A 层 **A2/A3/A6 是硬闸**：任一不过，本端口直接判 ❌ 不可用于归因任务。
>
> **A6 判读纪律（8095 轮教训，2026-11-10 补）**：必须**逐份人工核对「答案行 + 推导」**，严禁用关键词正则（如「含 √3」）代替判定。8095 实测 5 份中不含 √3 的 3 份同样全错（分界点 0/1 混淆、`f(0)` 极值点错、1 份空答案），用正则会**假阳性 3/5**。另：「未截断（`stop`）」只说明生成完毕，**不等于收敛正确**——8095 5/5 `stop` 但 5/5 收敛到错答/空答。
>
> ### Stage A0 · 思考档操纵检验（先于 A1，2026-11-10 依 8094 思考轮 QA 裁定修订）
>
> ⚠️ **本节取代 2026-11-09 初版**：初版要求「`/props` 的 `reasoning_format` 生效 + 至少一份 `reasoning_content>0`」，其中「`/props` 生效」一条已由 8094 思考轮证伪——`/props` 同样报 `none` 却分离出 8160 字符 reasoning，故该约束**既不充分也不必要，予以删除**。
>
> | # | 条文 | 依据 |
> |---|---|---|
> | **A0-1** | **唯一生效金标准**：至少 1 份**实际响应** `reasoning_content>0`，方可宣称「思考档已生效」；`/props` 的 `reasoning_format` / `reasoning_in_content` **降级为参考信息，不得单独作判据** | 8094 思考轮 `none` 却 >0；8095 `none` 且 =0，双向证伪其决定性 |
> | **A0-2** | **对照有效性**：同配置下须存在 `reasoning_content=0` 的关档对照（如显式 `enable_thinking:false`），否则 A/B 不构成有效自变量、结论作废 | 8095 三档全 0 → 作废；8094 思考轮 C 档 0 → 对照成立 |
> | **A0-3** | **生效 ≠ 可用**：生效后仍须逐份过 A2（`stop`）、A3（`content>0` 且无 `<think>`）；`length` 样本按 A2 作废，**不得用其 `reasoning_content` 里的推导替代答案行判 A6** | 8094 思考轮 A/B 思考链写到 `x=±1` 但 content=0 |
> | **A0-4** | **记录要求**：同时记录 `/props` 两字段值与每份 `reasoning_content` 长度；冲突时**以响应实测为准**并登记「事实偏差／字段语义待查」 | `/props=none` 却分离出 reasoning 的底层机制未明，不臆造 |
>
> **边界**：A0 是「生效」的唯一金标准，**不是「可用」的判据**；可用仍由 A2/A3/C1/C2 裁决，不得把金标准扩大成放行依据。
> **8095 存档结论加注**：结论（❌ NO-GO）不变；「`/props=none` 是服务端总闸」一句已撤回，8095 未生效的决定性证据是 **5/5 `reasoning_content=0`**（含显式 true 档），机制标「待查」。
> **A3 表格行修订**：去掉「检查 `reasoning_format`／`none` 已正确，勿动服务层」的措辞——该字段不控制思考是否生效；改为按 A0-1 以响应实测判定。

## 6. 判定等级与「如何合格」总对照

| 等级 | 含义 | 判定条件 |
|---|---|---|
| ✅ **合格（可用于归因）** | A 层全过 + B2 FAIL=0 + B6 门禁 PASS + C1/C2 达标 | 可进入生产接线评估 |
| ⚠️ **有条件 / 待优化** | A 层全过、B6 未过但 FAIL≤2 且陷阱 100% | 可继续调 prompt；记录具体失败题 |
| ❌ **不合格** | A2/A3/A6 任一不过，或 B2 FAIL≥3，或 B6 FAIL>0 | 按下面路径修 |

**不合格的四类根因 → 对应动作（不要乱试）**：

| 根因 | 典型症状 | 唯一有效动作 | 无效动作（别浪费时间） |
|---|---|---|---|
| 极低量化信息损失 | 驻点 ±√3、占位符、`</br>`、自我纠缠、自相矛盾 | **换高精度量化档**（Q3_K_M/Q4_K_M 或 9B Q5_K） | 调 temperature / top_p / seed / n_ctx |
| 答案行套模板 | 推导对但答案行写反、反号题 0/2 | **prompt / 解码约束层**加逐字搬运约束 | 换档、开思考档、加显卡 |
| 思考档截断 | `finish_reason=length`、`content=0`、70s+ | **请求层禁 `enable_thinking:true`** | 改服务 `reasoning_format`（本来就是 `none`） |
| 算力不足 | decode R <35 tok/s、p95>30s | 小模型高精度 / GPU offload | 加 `max_tokens`、降 `min_p` |

## 7. 诚实边界（每次报告必须带上）

- 全部为**离线 `prompt:ab` 直连 provider** 口径：不含 3001 API、上传/OCR、RAG 锚点注入、联网检索、多轮追问；生产端到端延迟必然更高。
- Stage A 为 **n=1~2 单次抽样**，只作定性线索；统计结论以 Stage B/C 为准。
- 跨端口对比存在**档位/口径差异**（bpw、思考档、题集模式），表中须标注分项口径，不做未标注的横比。
- **G1 真实用户认可率 ≥70%（n≥250）+ 人工盲评 ≥80% / κ≥75%** 不可由任何离线指标替代，永远单独标注「未做 / 不可判」。
- **数据主权**：请求与产物均在本机与本地 `reports/` 闭环，未外发、未参与训练或第三方共振。

## 8. 每端口复现命令模板

```bash
# ① Stage A：/props + 1 题裸请求直连
curl -s --noproxy '*' http://127.0.0.1:<PORT>/props
bash reports/<PORT>-eval/run-eval.sh --provider real \
  --set apps/api/src/tests/fixtures/prompt-ab-set-monotonic.json \
  --variants v0.2b-guard-trap --limit 1 --tag <PORT>-smoke

# ② Stage B：12 题 + auto-eval
bash reports/<PORT>-eval/run-eval.sh --provider real \
  --set apps/api/src/tests/fixtures/prompt-ab-set-monotonic.json \
  --variants v0.2b-guard-trap --tag <PORT>-mono
node apps/api/src/tests/auto-eval.mjs --json reports/prompt-ab-*-<PORT>-mono.json \
  --set apps/api/src/tests/fixtures/prompt-ab-set-monotonic.json --verbose

# ③ Stage C：34 题 + auto-eval + 回归门禁
bash reports/<PORT>-eval/run-eval.sh --provider real \
  --set apps/api/src/tests/fixtures/prompt-ab-set-realexam.json \
  --variants v0.2b-guard-trap --tag <PORT>-real
node apps/api/src/tests/auto-eval.mjs --json reports/prompt-ab-*-<PORT>-real.json \
  --set apps/api/src/tests/fixtures/prompt-ab-set-realexam.json --verbose
NO_PROXY='*' JSON=reports/prompt-ab-*-<PORT>-real.json npm run attrib:regress:real
```

> `run-eval.sh` 必须钉死：`NO_PROXY='*'`、清空代理变量、`AUTO_FALLBACK_TO_MOCK=false`（防静默跑假模型）、`DISABLE_THINKING=true`（防 70s+ 截断）。
