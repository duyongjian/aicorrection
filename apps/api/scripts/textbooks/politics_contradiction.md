# 矛盾论（唯物辩证法核心范畴）

矛盾规律即对立统一规律，是唯物辩证法的实质与核心。

## 矛盾的同一性与斗争性

同一性指矛盾双方相互依存、相互贯通，在一定条件下共处于一个统一体中，并相互转化；
斗争性指矛盾双方相互排斥、相互对立。同一性是相对的、有条件的，斗争性是绝对的、无条件的。
事物发展是同一性与斗争性共同作用的结果。

## 矛盾的普遍性与特殊性

普遍性：矛盾存在于一切事物中，并贯穿每一事物发展过程的始终（共性、绝对、无条件）。
特殊性：不同事物的矛盾及每一侧面各有其特点（个性、相对、有条件）。
关系：普遍性寓于特殊性之中，并通过特殊性表现出来；特殊性也离不开普遍性。
方法论：坚持具体问题具体分析，反对"一刀切"；做到普遍原理与具体实际相结合。

## 主要矛盾与次要矛盾

复杂事物中往往包含多个矛盾，其中必有一种处于支配地位、起决定作用，即主要矛盾；
其余为次要矛盾。办事情要着重抓住主要矛盾，同时统筹兼顾次要矛盾（"两点论"与"重点论"统一）。
矛盾的主要方面决定事物的性质；看问题要分清主流与支流。

## 内因与外因

内因是事物变化发展的根据（第一位原因），外因是条件，外因通过内因而起作用。
方法论：重视内因，又不忽视外因。

## 矛盾的精髓

矛盾的普遍性与特殊性、共性与个性的关系，是关于事物矛盾问题的精髓，
也是建设中国特色社会主义的哲学依据之一。
