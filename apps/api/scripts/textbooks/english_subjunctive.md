# 虚拟语气（Subjunctive Mood）

虚拟语气用于表达假设、愿望、建议、要求等非真实或主观语气，不表示客观事实。

## 与现在事实相反

条件从句用一般过去时（be 动词统一用 were，含 I/he/she），主句用 "would / could / might + 动词原形"。
例：If I were you, I would take the offer.（事实：我不是你）
注意：口语中 I was 偶见，但正式书面与考试标准答案一律用 were。

## 与过去事实相反

条件从句用过去完成时（had + 过去分词），主句用 "would / could / might + have + 过去分词"。
例：If he had left earlier, he would have caught the train.（事实：他没早走，没赶上）

## 与将来事实可能相反（推测）

条件从句用 "should + 原形 / were to + 原形 / 一般过去时"，主句同现在相反结构。
例：If it should rain tomorrow, we would stay home.

## 虚拟语气的倒装（省略 if）

条件从句含 were / had / should 时，可省略 if 并倒装：Were I you (= If I were you)；
Had he left (= If he had left)；Should it rain (= If it should rain)。
不可用于带动词 be 以外的普通过去式（如 did 不能倒装成 Did he go）。

## 建议/要求/命令类虚拟（宾语从句）

suggest / demand / insist / require / order / propose 等词后的宾语从句，谓语用
"(should) + 动词原形"，should 可省。例：I suggest he (should) apologize.
同类词还包括 necessity / recommendation 等名词性从句（It is necessary that he be present）。
